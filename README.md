# service-starter

Minimal service starter enforcing the engineering workflow (Playbook / Template / Starter kit).

What this is: a long-lived service skeleton with health probes, structured JSON logs, expand-contract migrations, and versioned contracts when triggered.

- Intent lives in Notion Home/Brief; this README does not duplicate it.
- Docs: `docs/` in this repo.
- Run: `task dev`
- Verify: `task verify`
